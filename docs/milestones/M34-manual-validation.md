# M34 manual validation — two Workers

1. Pair two Worker devices to the same seller.
2. Open **Seller → Workers**. Both appear with independent status and assignment counts.
3. Assign only the second Worker to a published capability version.
4. Confirm the offline or unassigned Worker does not receive that capability's jobs.
5. With both online and assigned, a new job is offered to the Worker with fewer active jobs.
